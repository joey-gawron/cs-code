# Tests CI leaves out of its required runs: timing budgets and environment checks that fail on a loaded or shared machine and pass alone
# (docs/handoff/known-issues.md names each one and why). One test per line: a test method's fully qualified name (a theory's every case),
# never a whole class, so the rest of its class keeps gating. A line starting "macos:" or "linux:" leaves the test out on that OS only (where
# known-issues saw it fail); a line without one, on both. '#' starts a comment. tools/ci/test-filter.sh turns this list into the
# `dotnet test --filter` expression of the OS it runs on. The CI workflow's "load-sensitive" job runs exactly these, without failing the
# build, so they are still watched. Remove a line once its test is fixed.
