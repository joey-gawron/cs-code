# Module brief — Vim emulation + Vim macros (`CsCode.Vim`)

**Owns:** `src/CsCode.Vim/**`, `tests/CsCode.Vim.Tests/**`, `tools/vim/**`, `docs/VIM.md`, a *Vim* section in `Directory.Packages.props` (only if you truly need a package; prefer none).
**Depends on:** `CsCode.Core` only (`KeyStroke`, `TextPosition/TextRange/TextEdit`, `ITextDocument`, `ICommandService`, `IConfigurationService`, `IStateStorage`, `Glob`, `Emitter`/`DisposableStore`). **No Avalonia.** Registers itself via `AddCsCodeVim(this IServiceCollection)`.
**Integration is a later step:** an adapter in the Editor/Shell wires `IVimHost` to the real editor and routes key events into `VimEngine`. You build the engine + the host abstraction + a headless in-memory host so it is fully testable *now*. Design `IVimHost` so that adapter is thin.

## Goal
A faithful, fast, deterministic **Vim engine** (not "vim-ish"): modal editing, operators × motions × text objects, registers, marks, dot-repeat, undo model, search, ex commands, mappings and **macros (`q`/`@`)**, matching real Vim semantics — verified by **differential testing against real Neovim** (`nvim` is on PATH at `~/.nix-profile/bin/nvim`; use `nvim --headless -u NONE -n -es`/`--embed`/Lua `nvim_feedkeys` to run the same keystrokes on the same buffer and compare resulting text, cursor, registers, marks, mode). Compatibility target for settings/behaviour that Vim itself doesn't define: **VSCodeVim** (`vim.*` settings).

## Threading (binding — ARCHITECTURE §6)
The engine runs **synchronously on the UI thread** inside key handling (it must, to be able to swallow keys and mutate the buffer atomically), so it must be *fast and non-blocking*: typical keys < 0.1 ms, no I/O, no awaiting, **no allocation in the hot path for common commands**, and **cooperative yielding** for big operations (`:%s`/`:g`/`gg=G`/`dG` on 100k+ lines): compute against a snapshot and apply as ONE batched `ApplyEdits`, or expose an `IVimWork` continuation the host runs in ≤ 4 ms slices — never block the UI > 50 ms. It must never wait on anything language-server related (LSP-backed actions like `gd`/`K` are fire-and-forget host commands).

## MUST
1. **Abstractions (public)**: `IVimBuffer` (line-oriented read access over a snapshot + `ApplyEdits` as one undo step + grapheme/surrogate-aware helpers), `IVimHost` (caret/selection incl. **block selection**, mode/showcmd/message line, viewport & wrapped-display-line queries (`gj/gk/g0/g$`), scrolling (`Ctrl-D/U/F/B/E/Y`, `zt/zz/zb`), folds, clipboard (`+`/`*` registers), search-highlight hooks, command-line UI hook (`:` prompt rendered by host), open/switch/close buffers & windows (`:e :w :q :bn :sp :vsp <C-w>…`), jump-to-location, `ExecuteCommand(id,args)` for app commands (`gd`→`editor.action.revealDefinition`, `gr`, `K`, `gc`…), timers (injectable `IVimTimer` for `timeoutlen`)), and `VimEngine` with `HandleKey(KeyStroke)` / `HandleText(string)` → `Handled | PassThrough`, `Reset()`, `Mode`, `PendingKeys`, events (`ModeChanged`, `MessageChanged`, `RecordingChanged`, `SearchChanged`). Provide `InMemoryVimHost` (over `InMemoryTextDocument`) used by all tests.
2. **Modes**: Normal, Insert, Replace, Visual (char/line/block), Operator-pending, Command-line (`:`, `/`, `?`), and Insert-Normal (`Ctrl-O`). Cursor-shape hints per mode for the host. `Esc`/`Ctrl-[`/`Ctrl-C` semantics incl. cursor adjust.
3. **Counts & registers**: `{count}` before/inside operators; registers `"` `0` `1-9` (shift rules, small-delete `-`), `a-z` / `A-Z` (append), `_` black hole, `.` `:` `/` `%` read-only, `+`/`*` via host clipboard (`vim.useSystemClipboard`), linewise/charwise/blockwise register types preserved; `:registers`/`:display`.
4. **Motions**: `h j k l`, `w W b B e E ge gE`, `0 ^ $ g_ | gm gM`, `f F t T ; ,`, `%` (pairs incl. comments/quotes sensibly), `( ) { } [[ ]] [] ][`, `H M L`, `gg G {n}G {n}%`, `+ - _ <CR> <BS> <Space>`, marks `` ` `` `'` (and `` `[ `] `< `> `. `^ `` ), `/ ? n N * # g* g#` with count, `gj gk g0 g$` (wrapped), `gn gN`, `go`, `Ctrl-O/Ctrl-I` jump list, `g; g,` change list; inclusive/exclusive/linewise motion rules incl. the `o_v/o_V/o_CTRL-V` forcing and the "exclusive→inclusive/linewise" special cases.
5. **Operators**: `d c y > < = g~ gu gU g? gq gw zf !(optional) g@(optional)`, doubled forms (`dd cc yy >> << == g~~ guu gUU g?? gqq`), `x X D C s S Y p P gp gP ]p [p J gJ ~ r R .`, `u Ctrl-R U`, `Ctrl-A/Ctrl-X` (numbers, hex, dates optional, with counts and visual `g Ctrl-A`), `&`/`g&`, `ga`-like info optional. Vim's *special cases*: `cw`→`ce`, `dw` at end of line, `d}` linewise promotion, `yy` + `P`, cursor position after each operation, count handling for `p`, indent rules with `shiftwidth`/`expandtab`/`tabstop`, `=` delegating to the host formatter.
6. **Text objects**: `iw aw iW aW is as ip ap i( a( ib ab i[ a[ i{ a{ iB aB i< a< i" a" i' a' i` a` it at`, counts, nesting, visual extension, whitespace rules identical to Vim.
7. **Visual modes**: `v V Ctrl-V`, `gv`, `o O`, operators on selections, **block mode** `I A c $ r J > <` incl. ragged lines and `$`-sticky, `v_p` replacing selection and register swap, `aw/ip` extension, `:` auto-range `'<,'>`, `gn`.
8. **Insert/Replace**: `i a I A o O gi gI`, counts (`3ihello<Esc>`), `Ctrl-W/U/H/R{reg}/O/V/K(digraphs optional)/T/D/[ /A/@/E/Y`, `Ctrl-N/P` completion → host hook, `Ctrl-X` submodes (stub), autoindent/smartindent basics, abbreviations optional, Replace-mode backspace restoring, `.` register, insert-mode **undo granularity exactly like Vim** (one undo step per insert session; `Ctrl-G u` / cursor-key breaks), `.` repeat of the last change including inserted text and counts.
9. **Undo model**: Vim's undo tree semantics sufficient for `u`, `Ctrl-R`, `U`, `:undo N`, `g- g+` (stretch), `:earlier/:later` (stretch); mapped onto the host's single undo stack by grouping `ApplyEdits` per Vim change.
10. **Search & regex**: translate Vim regex (`magic` default, `\v`, `\V`, `\m`, `\M`, `\<`, `\>`, `\{n,m}`, `\+ \? \= \|`, `\( \)`, `\zs \ze`, `\_s \_.`, character classes `[:alpha:]`, `\d \w \s \a \l \u`, `\c \C`, `~`, `&` in replacement, `\r \n \t`, `\0-\9`, `\u\l\U\L\E` case modifiers) to .NET regex with a documented list of unsupported items; `ignorecase`/`smartcase`/`wrapscan`/`incsearch`/`hlsearch`, offset forms (`/pat/e+1`), `n/N` direction memory, `*`/`#` word boundaries, `:noh`. Pattern work on large buffers is cooperative (see Threading).
11. **Ex commands**: ranges (`.` `$` `%` `'a` `'<,'>` `/pat/` `?pat?` `+n` `-n` `;`), `:w :q :q! :wq :x :wa :qa :e :enew :bn :bp :bd :ls :b N :sp :vsp :new :only :close :sav`, `:d :y :pu :m :t/:co :j :> :< :normal :norm! :s (flags & c g i I n e p # l, `&&`, `:&`, `:~`, any delimiter) :g :v :g!/:global with `normal` :noh :reg :marks :jumps :changes :undo :redo :set/:setlocal/:se (ignorecase smartcase hlsearch incsearch wrapscan number relativenumber tabstop shiftwidth softtabstop expandtab autoindent smartindent scrolloff sidescrolloff cursorline wrap list foldenable timeout ttimeout timeoutlen virtualedit startofline) :map family (`map nmap imap vmap xmap smap omap cmap` + `noremap` variants + `unmap` + `mapclear`, `<leader>`/`<localleader>`, `<C-x> <A-x> <S-x> <CR> <Esc> <Space> <Tab> <BS> <Del> <Up> … <F1-12> <Plug> <silent> <expr>(stretch) <nowait>`, recursion limit 1000, `timeoutlen` disambiguation of ambiguous prefixes via `IVimTimer`) :let/:echo (tiny subset) :source :@ `:{range}normal`, `:!`/`:r !` NOT supported (document), `:help` (opens docs URL via host). Error messages identical to Vim where tests compare them (`E492: Not an editor command`, `E486: Pattern not found`, …).
12. **MACROS (Vim)**: `q{a-z0-9}` start recording / `q` stop (status shows `recording @a`), `qA` appends, `@{reg}`, `@@`, `{count}@a`, `@:`, `:@a`, `:{range}normal @a`, `"ap`/`"ayy`/`:let @a=…`/`"Ayy` **edit macros as text in registers** (register text round-trips exactly, special keys encoded as Vim does — `<80>kb` style — or via an internal key-token representation with a lossless text round trip documented), recursive macros (`qaq qa …@aq`), **abort-on-error** semantics (a failing motion/search/`f` stops the rest of the macro and any enclosing count, like Vim), nested macro execution, macro under `:g`/`:normal`, `Ctrl-C` interrupt, runaway guard (op budget + wall-clock), macros recorded **before** mappings are applied (Vim records typed keys, not mapped expansions), dot-repeat interaction. **Persist registers** across sessions in `IStateStorage` (`vim.persistRegisters`, default on for a–z, capped).
13. **VSCodeVim-compatible configuration** (`vim.*`, registered via `IConfigurationService.RegisterProperties`, live-reloaded): `useSystemClipboard`, `leader`, `hlsearch`, `incsearch`, `ignorecase`, `smartcase`, `wrapscan`, `startInInsertMode`, `timeout`, `handleKeys` (`{"<C-c>": false, "<C-f>": false}` → pass those keys to the editor instead of Vim), `normalModeKeyBindings`, `normalModeKeyBindingsNonRecursive`, `insertModeKeyBindings(+NonRecursive)`, `visualModeKeyBindings(+NonRecursive)`, `operatorPendingModeKeyBindings(+NonRecursive)`, `commandLineModeKeyBindings`, binding entries `{ "before": ["j","j"], "after": ["<Esc>"], "commands": [{"command":"…","args":[…]}] }`, `cursorStylePerMode`, `autoSwitchInputMethod` (ignore), plus a `~/.cscode/vimrc` (or `{UserDataDir}/vimrc`) file parsed with the subset of Ex above (`set`, `map` family, `let mapleader`, `nnoremap` …) loaded at startup (errors reported, never fatal).
14. **Built-in plugin emulations** (VSCodeVim parity, toggled by `vim.surround`(default true), `vim.commentary`(true), `vim.sneak`(false), `vim.easymotion`(false stretch), `vim.camelCaseMotion`(false), `vim.argumentObjects`(false), `vim.replaceWithRegister`(false), `vim.highlightedyank`(host hook), `vim.targets`(false)): **vim-surround** (`ys{motion}{char}`, `yss`, `ds{char}`, `cs{old}{new}`, visual `S{char}`, tag surrounds `<q>`/`t`, `ysiw)` vs `ysiw(` spacing semantics) and **vim-commentary** (`gc{motion}`, `gcc`, visual `gc`) using the language's comment tokens from a host callback. Others are STRETCH.
15. **App-level commands** registered by `AddCsCodeVim`: `vim.toggle` (Toggle Vim Emulation), `vim.enable`, `vim.disable`, `vim.showCheatSheet`; setting `vim.enabled` (default false for now; the shell flips the default later).

## Tests (`tests/CsCode.Vim.Tests`, xUnit v3)
1. **≥ 800 table-driven cases** (`keys` → expected buffer text, cursor, mode, registers, marks) covering every command group above, written as compact data files (e.g. `.vimtest` text format: initial buffer with a cursor marker, key string like `d2w`, `ci"`, `qaA;<Esc>jq3@a`, expected buffer) so adding cases is cheap.
2. **Differential suite against real Neovim**: `tools/vim/run-nvim.sh`/a C# helper that runs each case in `nvim --headless -u NONE -i NONE -n` (via `--embed` msgpack-RPC or `-es` with `:normal`/`feedkeys`, whichever is robust) with identical options (`set nocompatible`, `shiftwidth`, `expandtab`, `noautoindent`… pinned in a preamble) and compares text/cursor/register/mark/mode state. **Run ≥ 400 of the table cases through it**; every divergence is either fixed or listed in `docs/VIM.md` as a documented, justified difference. Skip with reason if `nvim` is absent. Include macro cases (counts, recursion, abort-on-error, append-record, `:normal @a` ranges, macros with search/`f`/text objects).
3. **Property/fuzz tests**: for random buffers and random single commands, `u` restores the original text/cursor; `.` after a change equals re-typing it; `{count}` forms equal repeated forms where Vim defines so; engine never throws or corrupts the buffer for random key soup (10k sequences × 50 keys); `ApplyEdits` always yields valid positions (surrogate pairs, CRLF, tabs, wide chars, empty buffer, last line without newline).
4. Mapping/timeout tests with a fake `IVimTimer` (ambiguous prefixes, `<nowait>`, recursion limit), ex-command parser tests (ranges, flags, delimiters, error messages), settings/vimrc loading, plugin emulations.
5. **Performance & memory**: per-key time and allocation budget on a 1 MB buffer for the 30 most common commands (assert allocations ≈ 0 for motions/`x`/`dd`/insert typing after warm-up); `:%s/a/b/g` and `dG`/`gg=G` on a 100k-line buffer complete correctly with the work-slicing/batching strategy and don't exceed the UI-blocking budget (measure max slice); registers/undo/jump lists are bounded (jumplist 100, changelist 100, register text cap configurable, macro history bounded) — `LeakAssert` after engine disposal; engine holds no reference to the buffer after `Detach`.
