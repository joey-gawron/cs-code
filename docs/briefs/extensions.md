# Module brief — Extensions (`CsCode.Extensions` + `host/extension-host`)

**Owns:** `src/CsCode.Extensions/**`, `host/extension-host/**` (JavaScript, CommonJS, **zero npm runtime dependencies**), `tests/CsCode.Extensions.Tests/**`, `tools/fetch-extension-fixtures.sh`, `docs/EXTENSION-HOST.md` (wire protocol), `docs/EXTENSION-COMPAT.md` (API coverage matrix), the *Extensions* section of `Directory.Packages.props`.
**Implements (Core):** `IExtensionService`; populates `IContributionRegistry`; registers providers into `ILanguageFeatureRegistry`; commands into `ICommandService`; diagnostics into `IDiagnosticService`; registers debug adapter factories/config providers into `IDebugService` **if resolvable**.
**Consumes (Core, via DI):** `IContributionRegistry`, `ILanguageFeatureRegistry`, `IDiagnosticService`, `ICommandService` (+`AddUnknownCommandResolver` for `onCommand:` activation), `IDocumentManager`, `IConfigurationService` (`RegisterProperties`, live mirror), `IWorkspaceService`, `IFileSystem`, `IFileWatcher`, `IWindowService`, `IStatusBarService`, `IOutputService`, `INavigationService`, `IStateStorage`, `IAppPaths`, `IContextKeyService`, optional `IDebugService`, optional `IMemoryMonitor`, `ILoggerFactory`.
**Does not touch:** Avalonia/UI, other modules.

## Goal
Run **real, unmodified VS Code extensions** (from Open VSX, as VSCodium does) in an out-of-process Node.js host with a `vscode` API shim, and make *declarative* extensions (themes, grammars, snippets, language configs, keybindings, icon themes) work **without starting Node at all**. Be honest and precise about coverage (`docs/EXTENSION-COMPAT.md`).

## Part A — C# side (MUST)
1. **Manifest loader**: parse `package.json` + `package.nls*.json` (`%key%` substitution, locale fallback), validate (publisher/name/version/engines), compute `ExtensionDescription` (id = `publisher.name` lower-cased), `engines.vscode` semver range check against a reported API version constant (`1.95.0`, setting-overridable) with a clear "incompatible" reason, `extensionDependencies` + `extensionPack` ordering (topological, cycle-safe).
2. **Contribution mapping** (all absolute paths, resolved against the extension dir, path-traversal-safe) into the Core records: `languages`(+configuration path), `grammars`, `themes`(→`ColorThemeContribution`), `iconThemes`, `snippets`, `keybindings`, `commands` (→ `CommandMetadata`), `menus` (→ `MenuContribution`, all menu ids incl. `commandPalette`, `editor/context`, `explorer/context`, `editor/title`, `view/title`, `debug/…`), `configuration` (→ `ConfigurationProperty` registered with `IConfigurationService`, supports array-of-sections and `properties`), `debuggers`, `breakpoints`, `jsonValidation`. Contributions are registered/removed live when extensions are enabled/disabled/installed/uninstalled. No Node needed for any of this.
3. **Discovery & lifecycle** (`ExtensionService : IExtensionService`): scan `IAppPaths.ExtensionsDir` and `<InstallDir>/extensions` (built-in), enabled/disabled state in `IStateStorage`, install from **VSIX** (zip with `extension/` prefix; **zip-slip safe**, entry-count and size caps, atomic install via temp dir + rename, replaces older version, removes obsolete versions on next start — files may be locked by the host), uninstall, enable/disable, update check. `InstallFromMarketplaceAsync` / `SearchMarketplaceAsync` against **Open VSX** (`https://open-vsx.org/api/-/search?query=&size=&offset=&sortBy=relevance`, `GET /api/{namespace}/{name}[/{version}]` for metadata, `files.download` URL, honour `targetPlatform` e.g. `linux-x64`/`universal`; resilient to missing fields; HTTP via a shared `HttpClient`, retry/backoff, bounded cache of search pages, download progress, SHA verification when the API provides it). **Never contact Microsoft's marketplace.**
4. **Activation events**: `*`, `onStartupFinished`, `onLanguage:<id>`, `onCommand:<id>`, `workspaceContains:<glob>`, `onDebug`, `onDebugInitialConfigurations`, `onDebugResolve:<type>`, `onFileSystem:<scheme>`, `onView:<id>`, `onUri`, plus the **implicit** events derived from `contributes` (commands, languages, debuggers, views…) as modern VS Code does. Wiring: `IDocumentManager.Opened` → `onLanguage`, `ICommandService.AddUnknownCommandResolver` → `onCommand`, workspace open → `workspaceContains` (use `IWorkspaceService.FindFilesAsync`), startup finished → `*`/`onStartupFinished` (after the shell signals idle — expose `ActivateByEventAsync`). Activation is lazy and **extension-by-extension**; dependencies activate first; failures are isolated (one bad extension never blocks others) and reported once to the Output channel "Extension Host" + a non-spammy message.
5. **Host process management** (`ExtensionHostProcess`): locate Node (`cscode.extensionHost.nodePath` → `PATH` → `{ToolsDir}/node/bin/node`); missing/too-old Node (< 18) → state `Stopped` with a single friendly, actionable message — never an exception storm. Start **lazily** only when an enabled extension with `main` needs activation. Args: `--max-old-space-size=<cscode.extensionHost.maxOldSpaceMb, default 512>`; env hygiene (don't leak secrets; set `VSCODE_*`-style vars extensions commonly read: `VSCODE_PID`, `VSCODE_NLS_CONFIG` minimal). Stdio = RPC channel (stdout) + log (stderr → Output). **Crash recovery** (detect exit, restart with backoff, re-register, re-activate previously active extensions, tell the user once), **graceful shutdown** (`deactivate()` with 5 s timeout then kill; kill the process tree on dispose), `RestartHostAsync`. Track RSS via `IMemoryMonitor.TrackChildProcess` (if present): restart above the cap.
6. **RPC** (`ExtensionHostRpc`): JSON-RPC 2.0 with `Content-Length` framing over the child's stdio using StreamJsonRpc (System.Text.Json formatter) — or a tiny hand-rolled implementation if StreamJsonRpc proves awkward with the host's framing; document in `docs/EXTENSION-HOST.md` (every method, params, results, error codes, ordering and cancellation guarantees, version handshake). Requests have timeouts and cancellation; the host-side and C#-side both tolerate the peer dying mid-request.
7. **Provider proxies**: for every `languages.register*Provider` call made in JS, register the matching Core provider (`ICompletionProvider`, `IHoverProvider`, `IDefinitionProvider`, `IReferenceProvider`, `IDocumentHighlightProvider`, `IRenameProvider`, `IDocumentFormattingProvider`, `ISignatureHelpProvider`, `ICodeActionProvider`, `IDocumentSymbolProvider`, `IWorkspaceSymbolProvider`, `IFoldingRangeProvider`, `ISelectionRangeProvider`, `ISemanticTokensProvider`, `IInlayHintsProvider`, `ICodeLensProvider`, `IDocumentColorProvider`) into `ILanguageFeatureRegistry` with the JS-supplied selector; calls proxy over RPC with cancellation; results mapped to Core models. Disposal from JS (or deactivation/host crash) removes the registration. Diagnostics from `languages.createDiagnosticCollection` → `IDiagnosticService` owner `ext:<extId>:<name>`.
8. **Host ⇄ C# services**: commands (both directions; `commands.registerCommand/executeCommand/getCommands`), `window.show*Message/showQuickPick/showInputBox/showOpenDialog/showSaveDialog/withProgress/setStatusBarMessage/createStatusBarItem/createOutputChannel (+LogOutputChannel)/showTextDocument/activeTextEditor(+selection)/visibleTextEditors/onDidChange*` (`INavigationService` + documents), `workspace.*` (folders, `getConfiguration` with a **synchronous mirror** pushed from C# and `onDidChangeConfiguration`, `openTextDocument`, `textDocuments`, `onDidOpen/Change/Close/SaveTextDocument`, `applyEdit`, `fs.*` via `IFileSystem`, `findFiles`, `createFileSystemWatcher` via `IFileWatcher`, `workspaceFolders`, `asRelativePath`, `getWorkspaceFolder`), `env.*`, `extensions.getExtension/all`, `Memento` (`globalState`/`workspaceState` persisted through `IStateStorage`, synchronous API over an in-host cache with write-behind), `SecretStorage` (file-backed, **documented as unencrypted**), `l10n`, `debug.registerDebugAdapterDescriptorFactory/registerDebugConfigurationProvider/startDebugging/onDid*/activeDebugSession/breakpoints` (→ `IDebugService` factories/providers), `tasks` (registration accepted, execution unsupported), `authentication` (registers accepted; `getSession` → undefined / unsupported, documented), `webview`/`customEditor`/`notebook` (**unsupported**: calling them must fail with a clear error, not crash the host — document in the matrix), `terminal` (`createTerminal` returns an inert object with a one-time warning unless a `ITerminalService` ever exists).

## Part B — the Node host (`host/extension-host/`, plain CommonJS, Node ≥ 18, no npm deps) (MUST)
* `main.js`: framing + RPC, `Module._load` hook that returns the `vscode` shim for `require('vscode')` (and resolves each extension's own `node_modules`), `process.on('uncaughtException'/'unhandledRejection')` isolation (log, attribute to the extension if possible, never kill the host), extension loading (`main` entry, `activate(context)` with a real `ExtensionContext`: `subscriptions`, `extensionPath`, `extensionUri`, `globalState`, `workspaceState`, `secrets`, `storageUri/globalStorageUri/logUri`, `asAbsolutePath`, `extensionMode`, `environmentVariableCollection` stub), `deactivate`, activation timing/budget logging (warn at > 2 s).
* The **`vscode` shim** in modules by namespace + `types.js`: `Uri` (parse/file/joinPath/with/fsPath/toString exactness incl. Windows paths & encoding), `Position/Range/Selection/Location/LocationLink/Diagnostic(+Severity/Tag/RelatedInformation)/TextEdit/WorkspaceEdit/CompletionItem(+Kind/Tag, `CompletionList`)/Hover/MarkdownString/ThemeColor/ThemeIcon/EventEmitter/Disposable/CancellationTokenSource/SnippetString/CodeAction(+Kind)/CodeActionKind/SymbolKind/DocumentSymbol/SymbolInformation/SignatureHelp(+Information/Parameter)/FoldingRange/SelectionRange/SemanticTokens(+Builder+Legend)/InlayHint/CodeLens/Color/ColorInformation/DiagnosticSeverity/StatusBarAlignment/ViewColumn/ConfigurationTarget/TextEditorRevealType/EndOfLine/TextDocumentSaveReason/FileType/FileSystemError/DebugAdapterExecutable/DebugAdapterServer/DebugAdapterNamedPipeServer/DebugAdapterInlineImplementation/ProgressLocation/TreeItem*`; `TextDocument` mirror (`getText(range)`, `offsetAt`, `positionAt`, `lineAt`, `getWordRangeAtPosition`, `validateRange/Position`, `version`, `isDirty`, `languageId`, `uri`, `lineCount`, `eol`) updated by incremental changes from C#; `languages.match(selector, document)` scoring identical to Core's `DocumentSelector`.
  Tier-1 = exactly what **`vscode-languageclient` v9** needs to run unmodified for a stdio server (document sync, all language feature registrations, diagnostics collections, `workspace.createFileSystemWatcher`, `window.createOutputChannel`, `commands`, `workspace.getConfiguration`, `workspace.workspaceFolders` + `onDidChangeWorkspaceFolders`, `window.withProgress`/`showMessage`, `extensions`, `env`, `Disposable` semantics). **Verify this empirically** (see tests).
* `node --test` unit tests for the pure-JS parts (types, Uri, selector matching, TextDocument mirror, RPC framing) under `host/extension-host/test/` — wired into the xUnit suite by a test that shells out to `node --test` (skip if Node absent).

## SHOULD
* `contributes.menus` `when` clauses preserved for the shell; `contributes.viewsContainers/views` parsed (no UI), `contributes.taskDefinitions`, `contributes.problemMatchers` parsed and ignored; `extensionKind` honoured (skip `ui`-only, `web`-only entries); `browser` entries ignored.
* Semantic-token and inlay-hint providers, `workspace.fs` watchers, `SecretStorage` encrypted with the OS keyring when available.
* Extension **recommendations/auto-update** (`extensions.autoUpdate`) off by default; update check on demand only.

## Tests (`tests/CsCode.Extensions.Tests`, xUnit v3 + `node --test`)
1. **Manifest**: golden parse of real manifests (include at least: a colour-theme extension, a language-pack-free language/grammar extension, a snippets extension, an extension with `debuggers`, one with `configuration` arrays) obtained by `tools/fetch-extension-fixtures.sh` from Open VSX into `.scratch/fixtures/` (idempotent, pinned versions, skip when offline) **plus** small hand-written fixtures committed under `tests/…/Fixtures/` for edge cases (nls substitution, bad paths `../../etc/passwd`, missing fields, cycles in dependencies).
2. **VSIX/zip-slip/limits**, install/uninstall/enable/disable flows with a real archive built in the test; Open VSX client against a local `HttpListener` fake **and** one live smoke test (search + metadata only; skip when offline).
3. **Host integration with committed fixture extensions** (`tests/…/Fixtures/ext-*`): hello-command (activate → registerCommand → execute from C# and from JS), configuration read + change event, Memento persistence across host restart, status bar/output channel/message round trips, document sync (open/edit/close mirrored incl. edits in both directions via `applyEdit`), **each provider kind** round-tripped through the registry with cancellation, diagnostics collection, debug adapter factory registration → `IDebugService`, activation events (lazy: Node process NOT started until needed — assert), `deactivate` called on shutdown, host kill -9 → automatic restart + re-activation, memory cap restart path, unsupported APIs fail cleanly.
4. **Real `vscode-languageclient` fixture**: a committed minimal extension (`ext-lsp-client`) whose `package.json` depends on `vscode-languageclient@9` (installed into `.scratch/fixtures/` by the fetch script via npm) launching a tiny committed Node LSP server (hover/completion/diagnostics) → verify through **`ILanguageFeatureRegistry` + `IDiagnosticService`** that the unmodified client library works.
5. **At least two real third-party extensions from Open VSX activated unmodified** and observed through Core registries (pick lightweight ones; e.g. a theme + a snippet/language extension for the declarative path, and one small JS extension that registers commands/providers, such as a bracket/rainbow, markdown helper or formatter — whatever you verify works; record exactly which in `docs/EXTENSION-COMPAT.md`).
6. **Leak/soak**: 20 host restarts, 200 activate/deactivate cycles, 5,000 provider calls — no zombie `node` processes, handle/thread counts stable, registries empty after shutdown, `LeakAssert` for registrations/proxies.

## Done when
