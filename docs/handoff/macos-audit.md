# macOS portability audit (2026-10-29)

Read-only audit of main 2a9226e and the unmerged branches (rust 110028c, clipboard 3a4440e, background e961800, remote cb2a9ce, treesitter 41e1b76, vim 8156162). Six area auditors, one skeptic per area, a completeness sweep. Nothing was built or run on a Mac. Full findings (code refs, macOS facts, fixes): `macos-audit-2026-10-29.json` (not copied here; on the Linux machine in .scratch/notes).

Severity after verification. No blockers: it should build and open a usable window on a Mac; never tried.

* **dbg-3** (main, S) Intel Macs get no netcoredbg download: the latest Samsung release has no osx-amd64 asset, and the installer and fetch script both refuse Intel. * **files-1** (main, S) Changing only the case of a folder name fails on macOS with 'Cannot move into itself'. By then Explorer has already closed the folder's tabs and applied the LSP rename edits..
